# Product Requirements Document (PRD)

## Implemented Scope (10 Core Modules)
1. **Identity, Organization & Workspace Management**: Registration, bcrypt password hashing, email verification tokens, password reset tokens, JWT + HttpOnly cookie session lifecycle, organization creation, invitations, workspace switching, 11 RBAC roles + granular permissions, subscription plans, org audit logs.
2. **Digital Asset Discovery & Acquisition**: Manual asset submission, safe ZIP archive upload, SSRF-hardened GitHub/GitLab/Bitbucket metadata sync, duplicate URL detection, configurable inactivity candidate discovery engine (`discovery_candidates`).
3. **Asset Registry & Lifecycle Management**: Central registry with unique `SL-YYYY-XXXXXX` asset codes, 17-state lifecycle machine (`canTransitionAssetStatus`), versioning (`asset_versions`), metadata (`asset_metadata`), and event history (`asset_history`).
4. **Ownership, Verification & Compliance**: Ownership declarations (`sole_author`, `corporate_owner`, `authorized_representative`, `co_owner`), contributor disclosures, license & strong-copyleft risk flagging, evidence records, specialist review queue, and dispute/takedown auto-suspension.
5. **AI-Powered Technical Intelligence**: Isolated Python FastAPI analyzer (`services/ai-analyzer`) + deterministic Node fallback performing Python AST parsing, JS/TS security sink scanning, credential/secret detection, dependency manifest inspection, maintainability/documentation scoring, and explicit limitation reporting.
6. **Commercial Valuation & Opportunity Intelligence**: Reusability score, revival effort hour/INR range, suggested value range, documented assumptions, uncertainty factors, confidence scoring, and qualified human override capability.
7. **Asset Marketplace & Discovery Experience**: Public & authenticated search/filtering, side-by-side comparison (`/marketplace/compare`), saved assets, buyer requirements, and explainable recommendations (`asset_matches`).
8. **Matching, Collaboration & Deal Management**: Buyer inquiries, inquiry-to-deal conversion, deal rooms, threaded messaging, due diligence requests, multi-revision offers, and SHA-256 hashed dual-signature agreements.
9. **Transactions, Licensing & Asset Handover**: Server-side commission calculation from `system_settings`, idempotent transaction initiation, Razorpay adapter + HMAC webhook verification, compliant manual invoice settlement confirmation, refund handling, and checksummed handover delivery/acceptance.
10. **Administration, Analytics, Security & Governance**: Admin KPI overview, user suspension/activation, org registry, verification queue, marketplace moderation, dispute resolution, AI job monitoring, immutable audit log viewer, and configurable pricing/commission settings.
