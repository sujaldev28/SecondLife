# Application Screenshots

No binary screenshots are currently stored in this directory. Once captured from the live deployment (`https://secondlife-delta.vercel.app/`) or local environment (`http://localhost:3000`), place clean PNG/WebP captures here using these filenames:

- `landing-marketplace.png` — Public landing page and marketplace listing explorer
- `owner-evaluation-report.png` — Owner asset evaluation dashboard showing technical, security, and commercial revival scores
- `deal-room.png` — Buyer/owner negotiation, offer history, and agreement signing view
- `admin-governance.png` — Platform admin analytics, verification queue, and security audit logs
